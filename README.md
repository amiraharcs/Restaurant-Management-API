Oaxaca Restuarant Management System

Project Overview
The Oaxaca Restaurant Management System is a software solution designed to help the Oaxaca restaurant group expand more rapidly while maintaining their high standard of customer service.

As Oaxaca grows, hiring and training waiting staff quickly has become a challenge. The restuarant management system aims to reduce staffing and training requirements by using technology to simplify and support key front-of-house tasks, without reducing the quality of customer care.

Purpose
The restuarant management system focuses on supporting or automating tasks traditionally handled by waiting staff, including:
- Taking customer orders
- Communicating orders to the kitchen
- Managing bills and payments
- Tracking table status

Key Requirements
The system must provide:
- A fast and intuitive user interface requiring minimal training
- Accurate and reliable order data
- Secure but simple authentication to protect customer and restaurant data

Project Folders:

Frontend - Contains all code relating to the frontend of the restuarant management system
Backend - Contains all code relating to the backend of the restuarant management system
